## 🏛️ Архитектура и концепция

Проект решает сразу две ключевые задачи современного интернета:
1. **Обход жестких блокировок DPI и ТСПУ без риска детекции**: В отличие от стандартных протоколов, **NaiveProxy** упаковывает трафик внутри настоящего сетевого стека Chromium (`cronet`). Для любого цензора и систем активного зондирования (DPI) ваши соединения на 100% идентичны обычному посещению защищенного HTTPS-сайта пользователем Google Chrome.
2. **Бесшовный доступ к российским и зарубежным ресурсам (Smart Cascade)**: При использовании каскадного шлюза в РФ ваши запросы к Госуслугам, Сбербанку, Т-Банку и локальным сервисам идут напрямую через московский IP (без капч, блокировок по гео-IP и задержек), а трафик к заблокированным сервисам (YouTube, Instagram, Telegram, AI-платформы) автоматически уходит в шифрованный туннель до европейского сервера.

```
                      ┌────────────────────────────────────────────────────────┐
                      │                 КЛИЕНТСКИЕ УСТРОЙСТВА                   │
                      │  iOS (Shadowrocket) / Android (NekoBox) / PC / Telegram│
                      └──────────────────────────┬─────────────────────────────┘
                                                 │
                        ┌────────────────────────┴────────────────────────┐
                        │ (Опция А: Прямой вход)                          │ (Опция Б: Через шлюз в РФ)
                        ▼                                                 ▼
        ┌───────────────────────────────┐                 ┌───────────────────────────────┐
        │      VPS Европа (443 TCP)     │                 │  VPS Москва (Каскадный шлюз)  │
        │                               │                 │   Sing-box Smart Split-Route  │
```

## ✨ Ключевые преимущества

| Возможность | Описание |
| :--- | :--- |
| **NaiveProxy (HTTP/2 CONNECT)** | Использует сетевой стек Chromium. Имитирует поведение настоящего браузера Chrome, делая трафик невидимым для эвристического анализа DPI. |
| **Telegram Web Proxy** | Официальный веб-прокси Telegram, работающий поверх единого 443 порта через SNI-мультиплексирование Caddy. Подключение в 1 клик на любом устройстве. |
| **Active Probe Resistance** | При неавторизованном доступе или попытке сканирования Caddy отдает легитимный камуфляжный сайт инженерной телеметрии без каких-либо намеков на прокси. |
| **Smart Russian Cascade** | Умная маршрутизация: ресурсы РФ открываются без задержек и капч через сервер в Москве, а международные сайты туннелируются в Европу. |
| **Автономный Telegram-бот** | Управление пользователями (`/new`, `/del`, `/list`), генерация QR-кодов, выдача готовых ссылок и мониторинг системных ресурсов. |
| **Безопасность Zero-Trust** | Бот работает от изолированного непривилегированного пользователя `proxy-bot` с ограниченным `sudo`-хелпером (`caddy-control`). |
| **Kernel Tuning & Firewall** | Автоматическая активация TCP BBR, SYN Cookies, защита от спуфинга и строгий межсетевой экран UFW + Fail2ban. |

## 🇷🇺 Схема каскадной маршрутизации (Smart Cascade)

При настройке каскада через сервер в России (`cascade/setup-cascade.sh`):

1. **Трафик к ресурсам РФ** (`.ru`, `.рф`, `sberbank.ru`, `tbank.ru`, `gosuslugi.ru`, `kinopoisk.ru`, `avito.ru`, `vk.com`, `yandex.ru`):
   - **Маршрут**: `Клиент ➔ Российский сервер ➔ Целевой сервис`.
   - **Результат**: Максимальная скорость, пинг 2–5 мс, отсутствие капчи Cloudflare/Qrator, полная доступность государственных сервисов.

2. **Международный и заблокированный трафик** (`youtube.com`, `instagram.com`, `x.com`, `chatgpt.com`, `telegram.org`):
   - **Маршрут**: `Клиент ➔ Российский сервер (шлюз) ➔ Шифрованный туннель HTTPS ➔ Зарубежный сервер (Европа) ➔ Интернет`.
   - **Результат**: Провайдер в РФ видит только легитимный HTTPS-трафик до московского сервера. Блокировки ТСПУ на трансграничных переходах не срабатывают.

## 💻 Требования к серверу

### Основной сервер (Зарубежный VPS — Нидерланды / Германия / Франция / Финляндия)
- **ОС**: Debian 11 / 12 или Ubuntu 22.04 / 24.04 LTS.
- **CPU / RAM**: 1 vCPU, 1 GB RAM (потребление памяти связки Caddy + Docker + Bot < 120 МБ).
- **Диск**: 10 GB NVMe.
- **Сеть**: Белый статический IPv4, порт 80 и 443 TCP.
- **Доменные имена**:
  - `vpn.yourdomain.com` — для NaiveProxy и сайта-камуфляжа.
  - `tg.yourdomain.com` — для Telegram Web Proxy.

### Каскадный сервер в РФ (по желанию)
- Любой дешевый VPS в Москве/СПб (например, за ~200–220 ₽/мес).
- 1 vCPU, 512 MB – 1 GB RAM.

## 🚀 Быстрая установка

### 1. Подготовка доменов
Создайте две A-записи у вашего DNS-провайдера (например, DuckDNS или Cloudflare), направленные на IP европейского сервера:
- `vpn.yourdomain.com` ➔ `IP_СЕРВЕРА`
- `tg.yourdomain.com` ➔ `IP_СЕРВЕРА`

> ⚠️ **Важно**: Если используете Cloudflare, отключите оранжевое облако (режим **DNS Only**).

### 2. Запуск установки на основном сервере
Подключитесь к серверу по SSH и выполните:

```bash
git clone https://github.com/Mizanov/stealth-proxy-cascade.git /opt/stealth-proxy
cd /opt/stealth-proxy
sudo bash install.sh
```

Установщик в интерактивном режиме запросит:
- Домен для NaiveProxy (`vpn.yourdomain.com`)
- Домен для Telegram Web Proxy (`tg.yourdomain.com`)
- Секретный ключ для Telegram Web Proxy (или сгенерирует криптографически стойкий автоматически)
- Токен Telegram-бота (от `@BotFather`)
- Telegram ID администратора (от `@userinfobot`)
- Домен или IP каскадного сервера в РФ (опционально)

Скрипт автоматически:
1. Скомпилирует **Caddy v2** с плагином `forwardproxy@naive` через `xcaddy`.
2. Развернет защищенный контейнер **Telegram Web Proxy**.
3. Настроит камуфляжный сайт с защитой от сканирования.
4. Выпустит доверенные TLS-сертификаты Let's Encrypt / ZeroSSL.
5. Запустит изолированного Telegram-бота с автозапуском в systemd.
6. Применит тюнинг ядра Linux (BBR) и фаервол UFW.

## 🤖 Управление через Telegram-бота

Бот защищен строгим модулем аутентификации `auth.py` (fail-closed) и отвечает только администраторам:

| Команда | Назначение |
| :--- | :--- |
| `/start` | Главное меню с быстрыми кнопками управления |
| `/new <username>` | Создать нового пользователя NaiveProxy, выдать конфигурацию и QR-код |
| `/list` | Показать список действующих пользователей с кнопками удаления |
| `/del <username>` | Отозвать доступ и мгновенно удалить пользователя из Caddyfile |
| `/proxy` | Получить ссылку мгновенного подключения Telegram Web Proxy в 1 клик |
| `/cascade` | Инструкция и параметры подключения через каскадный шлюз |
| `/status` | Мониторинг состояния Caddy, Docker, диска и оперативной памяти |

## 📱 Настройка клиентов

### 1. Telegram (Смартфон / ПК)
- Просто откройте ссылку вида `tg://proxy?server=tg.yourdomain.com&port=443&secret=...` выданную ботом (или нажмите кнопку **🚀 Telegram Web Proxy**).
- Telegram подключится мгновенно через зашифрованный HTTPS-канал.

### 2. iOS (Shadowrocket)
1. Нажмите **`+`** в правом верхнем углу.
2. Выберите тип: **HTTP2** или **SOCKS5 over TLS** (в зависимости от версии клиента) / импортируйте ссылку `https://user:pass@vpn.yourdomain.com:443`.
3. В поле **Server** укажите `vpn.yourdomain.com`, порт `443`.
4. Включите **TLS**, укажите логин и пароль, выданные ботом.

### 3. Android (NekoBox / Matsuri)
1. Нажмите **`+`** ➔ **Manual Settings** ➔ **Naive**.
2. Введите адрес сервера `vpn.yourdomain.com`, порт `443`.
3. Укажите логин и пароль.
4. Включите SNI: `vpn.yourdomain.com`.

### 4. Windows / macOS / Linux (Официальный клиент NaiveProxy)
Скачайте бинарник [NaiveProxy Release](https://github.com/klzgrad/naiveproxy/releases) и создайте файл `config.json`:

```json
{
  "listen": "socks://127.0.0.1:1080",
  "proxy": "https://USERNAME:PASSWORD@vpn.yourdomain.com:443"
}
```

Запустите: `./naive config.json`. На порту `1080` появится локальный SOCKS5-прокси.

## 🇷🇺 Развертывание каскада на сервере в РФ

Чтобы поднять шлюз с умной маршрутизацией на сервере в Москве:

1. Подключитесь к вашему российскому VPS по SSH.
2. Скопируйте и запустите установочный скрипт:

```bash
# Передайте адрес вашего европейского сервера NaiveProxy
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/Mizanov/stealth-proxy-cascade/main/cascade/setup-cascade.sh || cat setup-cascade.sh)"
```

Скрипт развернет **Sing-box**, загрузит актуальные гео-базы (`geoip-ru`, `geosite-category-gov-ru`, списки доменов Яндекса, VK, банков) и поднимет локальный шлюз с автоматическим сплит-туннелированием.

## 🔒 Безопасность и защита от зондирования

- **Probe Resistance**: Директива `probe_resistance` в Caddyfile закрывает прокси от активных сканеров сетевой цензуры. Если запрос не содержит валидного заголовка авторизации `Proxy-Authorization`, сервер ведет себя в точности как обычный веб-сайт.
- **Изоляция привилегий**: Управляющий бот работает под системным пользователем `proxy-bot` без shell-доступа (`/usr/sbin/nologin`). Изменение конфигурации выполняется через атомарный скрипт-хелпер `/usr/local/bin/caddy-control` с валидацией путей и защитой от Path Traversal.
- **Fail-Closed Auth**: Если переменная `TELEGRAM_ADMIN_IDS` повреждена или пуста, бот немедленно блокирует любые операции.
- **Сетевая защита**: Закрыты все неиспользуемые порты, настроен Fail2ban (бан на 24 часа за перебор паролей SSH).
